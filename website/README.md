# MockQL Rust Docs

This website is built with [Docusaurus](https://docusaurus.io/) and managed with Bun.

## Running Locally

```sh
bun install
bun run start
```

## Building

```sh
bun run build
```

## Cutting a Docs Version

When the project needs versioned documentation, snapshot the current docs:

```sh
bun run version 0.1.x
```
